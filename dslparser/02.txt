## Meetings, email, and priorities

### Step 1. Prepare for a meeting

@editor The fictional names are intentionally international.
@media audio "audio/weekly meeting.ogg"
@editor {
The pauses in the recording give learners time to take notes.
Do not shorten them during editing.
}
@script Weekly meeting {
Maya: First, let’s review last week’s actions.
Omar: I finished the customer survey.
Lina: I’m still working on the budget.
Maya: Fine. Let’s discuss the launch date next.
}

@task meeting-language
@instr Notice how the speakers move from one topic to another.
@example Signposting {
First, let’s review last week’s actions.
---
Let’s discuss the launch date next.
}
@choice {
First, let’s review our actions.
The actions first review let us.
}
@question What phrase does Maya use to introduce the next topic?

@task minutes
@instr {
Complete the meeting notes.
Use short phrases rather than full sentences.
Write one action for each person.
}
@multifill Complete the minutes. {
Maya: _____
Omar: _____

Lina: _____
}
@key Suggested notes {
Maya: confirm the launch date
Omar: share the customer survey
Lina: finish the budget
}

### Step 2. Write a helpful email

@text Email principles {
A helpful email has a clear subject line and a specific request.

Use <strong>please</strong> for a polite request, and state the deadline clearly.
Write <em>thank you</em> when the reader’s help is required.
}

@example Please send the revised figures by 3 p.m. on Thursday.
@note Keep the request specific and realistic.
@alt Use a message in the team chat if that is your workplace convention.

@task email-edit
@instr Improve the email below.
@multifill Edit the message. {
Subject: Stuff

Hi,
Send me the file soon.
Thanks.
}
@multichoice {
Add a precise subject line.
Name the required file.
Give a clear deadline.
Remove every greeting.
}

@task email-reply
@instr Write a reply that confirms the request and deadline.
@multifill Write 60–80 words.
@key {
The reply should confirm what will be sent and when it will be sent.
It should also mention any genuine problem with the deadline.
}
