# Диагностики

Все коды представлены типом `DiagnosticCode`. Фатальные коды возвращаются через `*FatalError`; локальные коды прикрепляются к узлу или элементу и входят в `Document.Diagnostics()`.

## Фатальные коды

| Код | Условие |
|---|---|
| `INVALID_UTF8` | Вход не является корректным UTF-8. |
| `MISSING_VERSION` | Первая физическая строка не содержит корректную непустую директиву `@dsl-version`. |
| `UNSUPPORTED_VERSION` | Указанная версия не зарегистрирована; реализована только 1.1. |
| `READ_FAILURE` | `ParseReader` получил `nil` либо чтение завершилось ошибкой. |

## Локальные коды

| Код | Условие и место |
|---|---|
| `EMPTY_TAG_NAME` | После `@` отсутствует имя; диагностика узла. |
| `MALFORMED_HEADING` | Заголовок нарушает форму с пробелом и текстом; диагностика узла. |
| `UNCLOSED_QUOTE` | Кавычка аргумента не закрыта; диагностика токена/элемента. |
| `INVALID_BLOCK_OPEN` | Строка открытия блока содержит недопустимую форму; диагностика узла. |
| `ORPHAN_BLOCK_CLOSE` | Закрывающая `}` не имеет открывающего блока; диагностика узла границы. |
| `INVALID_BLOCK_CLOSE` | В строке закрытия есть дополнительные символы; диагностика узла границы. |
| `UNCLOSED_BLOCK` | Для открытого блока не найдена закрывающая граница; диагностика тега. |
| `UNSUPPORTED_TAG_FORM` | Известный тег использован в незарегистрированной inline/block-форме; диагностика тега. |
| `MISSING_SEPARATOR` | В shaped-теле отсутствует обязательный `---`; диагностика элемента. |
| `MULTIPLE_SEPARATORS` | В shaped-теле найден лишний `---`; диагностика элемента. |
| `STEP_OUTSIDE_TASK` | `@step` расположен вне задания; диагностика узла. |
| `ENDTASK_WITHOUT_TASK` | `@endtask` не соответствует открытому заданию; диагностика узла. |
| `SPEAKING_CONTEXT` | `@speaking` использован вне допустимого контекста шага; диагностика узла. |
| `VARIANT_OUTSIDE_VARIANTS` | `@variant` находится вне `@variants`; диагностика узла. |
| `NESTED_VARIANTS` | `@variants` вложен в другую область вариантов; диагностика узла. |
| `CONTENT_BEFORE_VARIANT` | В `@variants` содержимое предшествует первой ветви; диагностика узла. |

Диапазон диагностики полуоткрыт. `Diagnostic.RelatedSpan` возвращает дополнительный диапазон и `true`, когда связь существует, иначе нулевой диапазон и `false`.
